# cold-manifest Web 服务 UX 架构设计 v0.3（配套文档）

> 配套主文档：`docs/升级方案-v0.3.md`。本文档面向设计与前端实现，只描述信息结构、页面行为、交互流程与呈现策略；不涉及后端接口、数据库表结构或命令行参数。
> 目标用户：懂技术、不想写 SQL、偶尔使用冷备盘的个人用户。平台：Windows / Linux，中文界面。

---

## 1. 信息架构与导航模型

### 1.1 一级栏目

采用**固定左侧导航 + 顶部上下文工具栏**的经典本地工具布局。左侧导航常驻 5 个一级入口，按使用频率与心智模型排列：

| 顺序 | 栏目 | 定位 | 典型访问频率 |
|------|------|------|--------------|
| 1 | **总览** | 所有磁盘、快照、健康状态、最近任务的一站式入口 | 每次打开 |
| 2 | **快照** | 单个快照的浏览、统计、搜索、目录树 | 高频 |
| 3 | **对比** | 两快照差异分析，含目录级汇总与文件级明细 | 中频 |
| 4 | **磁盘** | 物理盘详情、SMART 历史、卷与盘符映射 | 低频但关键 |
| 5 | **任务** | 采集、导入、导出、报告生成的配置与进度 | 每次接新盘 |

底部固定入口：**设置**（图标齿轮，不纳入主要流程）。

### 1.2 全局导航元素

- **应用标题栏**：左侧显示应用名与当前环境标签（如 `cold-manifest · 本地服务`），右侧显示服务状态指示灯（运行中 / 任务进行中 / 出错）。
- **左侧导航**：图标 + 文字，当前项高亮；当某个栏目下有未完成的重要任务时显示小型徽标（例如任务栏显示“1 个采集中”）。
- **全局搜索框**：顶部栏右侧放置“快速搜索”，回车后进入搜索页并预填关键词；支持快捷键 `Ctrl/Cmd + K`。
- **通知中心**：右上角铃铛图标，聚合任务完成、错误、磁盘接入/拔出事件；点击展开抽屉，保留最近 50 条。

### 1.3 面包屑与上下文操作

- **面包屑**：用于快照浏览、目录下钻、对比结果三类深导航页面，形式为 `快照 / photos / 2023 / 事件`。
- **上下文工具栏**：进入具体快照或对比会话后，顶部出现该对象的专用工具栏，包含：
  - 快照名 / 对比会话名
  - 关键指标（文件数、总大小）
  - 主要操作按钮（导出、刷新、关闭）
  - 视图切换（列表 / 图表 / 树）
- **右键菜单**：文件与目录行支持右键唤起“复制路径”“在资源管理器中打开”“加入筛选”等操作。

### 1.4 页面状态约定

- **空态**：页面首次使用或没有数据时，中央展示插画 + 一句说明 + 一个主操作按钮（如“接入磁盘并采集”）。
- **加载态**：表格骨架屏，目录树节点显示旋转占位，进度页显示实时日志与百分比。
- **错误态**：顶部红色横幅 + 可展开的“详情”区域；不影响页面其他可用区域。
- **部分失败**：采集或对比过程中出现可恢复错误（如部分文件跳过）时，用黄色警告条提示，并提供“查看日志”入口。

## 2. 页面清单与每页规格

### 2.1 总览仪表盘（首页）

**目的**：一眼掌握“有多少盘、最近做了什么、有没有异常”。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 顶部 KPI | 4 个统计卡片 | 磁盘数 / 快照总数 / 最近一次采集时间 / 待关注任务数 |
| 磁盘列表 | 表格 | 每行一块物理盘：别名、型号序列号、容量、最近快照日期、健康状态徽标、操作入口 |
| 快照时间线 | 横向时间轴 | 按磁盘分组，展示历次快照节点；点击节点进入快照概览 |
| 最近活动 | 时间倒序列表 | 最近 10 条采集/导入/对比/导出任务，含状态与耗时 |
| 告警区 | 可折叠面板 | SMART 异常、快照过期（超过用户设定天数未采）、任务失败 |

**主要操作**：
- “开始采集”主按钮（进入采集任务页）
- “导入旧快照”次按钮
- 磁盘行点击 → 磁盘详情；快照节点点击 → 快照概览

**空态**：未接入任何盘时显示“尚未发现磁盘”，并引导采集或导入。

**错误态**：服务未就绪时全页显示红色遮罩层，并提供“重试启动”。

---

### 2.2 快照概览

**目的**：展示单个快照的统计画像，帮助用户快速判断“这张快照长什么样”。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 快照信息头 | 标题 + 元数据 | 快照名、所属磁盘、采集时间、持续时间、是否含哈希、备注 |
| 核心统计 | 4 个 KPI 卡片 | 文件总数 / 目录总数 / 总逻辑大小 / 实际占用空间 |
| 文件类型分布 | 环形图 / 横向条形图 | 按扩展名聚合 Top 10，其余归入“其他” |
| 文件大小直方图 | 柱状图 | 横轴为对数区间（<1KB / 1KB–1MB / 1MB–1GB / 1GB–10GB / >10GB），纵轴为文件数 |
| 顶层目录占用 | 树图 / 横向条形图 | 每个顶层目录的聚合大小，支持点击进入目录浏览 |
| 最大文件 Top-N | 表格 | 默认 Top 50，列：名称、路径、大小、修改时间；支持点击路径进入目录 |
| 最近修改 Top-N | 表格 | 按修改时间倒排，默认 50 条 |

**主要操作**：
- “浏览目录”进入快照浏览页，默认定位根目录
- “搜索本快照”进入搜索页并绑定当前快照
- “导出报告”打开导出抽屉
- “与上一个快照对比”自动选取同盘上一次快照作为 B，进入对比页

**空态/加载态**：快照尚未完成统计时显示骨架屏；数据缺失时隐藏对应图表而不是显示空白。

---

### 2.3 目录浏览与文件列表

**目的**：像资源管理器一样逐层查看快照内容，同时能查看目录聚合信息。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 左侧目录树 | 懒加载树形组件 | 根节点为盘符/挂载点；点击三角展开，异步加载子目录；当前节点高亮 |
| 右侧文件列表 | 虚拟滚动表格 | 列：名称、大小、修改日期、扩展名、属性（隐藏/系统/只读图标） |
| 目录信息头 | 路径面包屑 + KPI | 当前目录名、本目录文件数、直接大小、聚合大小（含子目录）、最近修改 |
| 视图切换 | 分段控件 | 图标视图 / 详细列表 / 仅目录树 |
| 排序与分页 | 表头排序 + 分页器 | 默认按名称升序；单页 200 条，超出时分页 |

**主要操作**：
- 目录树点击 → 右侧列出该目录内容
- 双击目录 → 进入该目录
- 点击文件 → 右侧滑出详情面板（文件大小、时间、路径、哈希若存在）
- 右键文件/目录 → 复制路径、在资源管理器中打开、搜索同扩展名
- “返回上一级”“返回根目录”快捷按钮

**空态**：空目录显示“此目录为空”提示；根节点未加载时显示骨架节点。

**性能策略**：目录树与文件列表均走服务端分页/懒加载，避免一次性加载百万行。

---

### 2.4 搜索页

**目的**：让用户用关键词、大小、时间、扩展名、属性组合快速定位文件。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 搜索条件区 | 表单 + 筛选器 | 关键词输入、目标快照选择、扩展名多选、大小范围、修改时间范围、属性开关 |
| 结果摘要 | 标签栏 | 命中数、搜索耗时、当前筛选条件胶囊 |
| 结果表格 | 虚拟滚动表格 | 列：名称、路径、大小、修改时间、扩展名；行高 40px |
| 结果操作栏 | 按钮组 | 导出当前结果、在目录树中打开、保存为快捷筛选 |

**主要操作**：
- 回车或点击“搜索”触发查询
- 点击结果行 → 目录浏览页滚动并高亮该文件
- 点击“在目录树中打开” → 自动展开路径直到目标节点
- 导出为 CSV（完整结果）

**空态**：无关键词时显示提示“输入关键词或选择筛选条件开始搜索”；无结果时给出“放宽条件”建议。

**性能策略**：全文索引能力支持毫秒级名称/路径搜索；结果超过 1,000 条时显示“已加载前 1,000 条，请继续细化条件”，并提供导出完整结果。

---

### 2.5 两快照对比视图

**目的**：清晰呈现两个快照之间的新增、删除、变更、改名/移动，并支持从目录汇总下钻到文件明细。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 对比控制头 | 标题 + 快照选择器 | A/B 快照下拉框、交换按钮、口径一致性检查提示 |
| 差异总览 | 4 个 KPI 卡片 + 类型过滤 | 新增 / 删除 / 变更 / 改名移动 四类数量与大小；点击卡片过滤下方列表 |
| 目录级汇总表 | 可展开表格 | 每行一个变更目录，列：目录路径、新增数、删除数、变更数、改名移动数、净大小变化；可展开显示子目录 |
| 文件级明细表 | 虚拟滚动表格 | 列：名称、A 路径、B 路径、变更类型、A 大小、B 大小、A 修改时间、B 修改时间 |
| 变更详情抽屉 | 滑出面板 | 点击文件行后展示两侧属性并排对比、哈希对比（若启用）、路径变化 |

**主要操作**：
- 选择 A/B 快照后点击“开始对比”
- 点击目录行下钻到该目录的变更明细
- 点击文件行打开详情抽屉
- 过滤：按变更类型、扩展名、大小变化范围过滤
- 导出差异报告（CSV / HTML）

**空态**：未选择快照时显示选择器占位；无差异时显示“两个快照完全一致”。

**错误态**：A/B 口径不一致（如一个含哈希一个不含）时，黄色提示条说明可能影响“改名/移动”识别，并允许用户继续。

---

### 2.6 变更下钻页

**目的**：在对比结果中，针对某个具体目录做深入查看。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 目录上下文头 | 面包屑 + 返回 | 当前目录路径、相对 A/B 的变更统计 |
| 变更类型切换 | 分段控件 / 标签 | 全部 / 新增 / 删除 / 变更 / 改名移动 |
| 文件明细表 | 同对比视图 | 仅展示当前目录及其子目录的变更文件 |
| 子目录汇总 | 内嵌小表 | 当前目录下各子目录的变更数量 |

**主要操作**：
- 从对比视图点击目录行进入
- 切换变更类型查看不同维度
- 点击文件行打开详情抽屉
- 点击“在快照浏览中打开”进入对应快照的目录树并定位

---

### 2.7 磁盘详情页

**目的**：展示物理磁盘身份、容量、历次快照、SMART 健康趋势。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 磁盘身份信息 | 信息卡片 | 型号、序列号、固件、接口、容量、真实盘符/挂载点、卷序列号 |
| 健康状态卡片 | 状态徽标 + 关键指标 | 整体健康（正常/警告/严重）、温度、通电小时、重映射扇区数、待映射扇区数 |
| SMART 历史曲线 | 折线图 | 历次采集时的温度、通电小时、待定扇区数趋势；无数据时隐藏 |
| 快照时间线 | 纵向时间线 | 该磁盘所有快照，点击节点进入快照概览 |
| 操作区 | 按钮组 | 立即采集、编辑别名、标记为报废/退役 |

**主要操作**：
- “立即采集”进入采集任务页并预填该盘
- 点击快照节点查看详情
- 编辑磁盘别名便于识别

**空态**：SMART 数据拿不到时显示“未获取到 SMART 数据（USB 硬盘盒常见）”，并提供“了解更多”提示。

---

### 2.8 采集任务页

**目的**：配置并执行一次新快照采集，实时查看进度与日志。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 配置区 | 表单 | 目标卷/盘符选择、快照别名、是否计算哈希（关闭/全量/抽样）、排除规则、备注 |
| 依赖检查 | 状态列表 | 是否可读取 SMART、是否有写权限保存快照文件 |
| 进度区 | 进度条 + 统计 | 已扫描文件数、已扫描目录数、已跳过数、预估剩余时间 |
| 实时日志 | 只读终端面板 | 滚动显示最近 100 条日志；支持暂停滚动、清空、复制 |
| 完成摘要 | 结果卡片 | 任务结束后显示文件数、目录数、总大小、跳过数、耗时、快照保存路径 |

**主要操作**：
- 选择目标卷后点击“开始采集”
- 采集过程中可“暂停/继续”“取消”
- 完成后可“查看快照”“再采一次”“返回首页”

**空态**：无可选卷时提示“未检测到可采集的磁盘”。

**错误态**：采集中断后，下次进入该页时提示“检测到未完成的采集，是否继续？”；失败任务提供日志下载。

---

### 2.9 导入旧快照页

**目的**：将旧版三个 CSV 文件转换并导入为新快照数据库。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 文件选择 | 拖拽上传/文件选择 | 选择 `metadata.csv`、`tree.csv`、`warnings.csv` |
| 映射预览 | 表格 | 预览前 10 行，显示识别到的列与数据样例 |
| 选项区 | 表单 | 目标磁盘选择、快照日期、别名 |
| 进度与结果 | 状态面板 | 导入进度、行数统计、错误行、跳过的重复记录 |

**主要操作**：
- 上传 CSV 后系统自动识别格式
- 确认映射后点击“开始导入”
- 导入完成后进入快照概览

**空态**：未选择文件时显示拖放区域与示例文件说明。

**错误态**：文件缺失或格式不匹配时，具体指出哪一列无法识别。

---

### 2.10 导出/报告页

**目的**：将快照或对比结果导出为可存档、可分享的格式。

**关键区块**：

| 区块 | 组件 | 说明 |
|------|------|------|
| 数据源选择 | 选择器 | 当前快照 / 当前对比 / 自定义选择 |
| 导出类型 | 单选 | HTML 报告 / CSV 清单 |
| 内容范围 | 复选框 | 总览 / 目录占用 / 最大文件 / 变更明细 / 跳过清单 / SMART 数据 |
| 高级选项 | 折叠面板 | 是否包含哈希列、编码（UTF-8/BOM UTF-8）、日期格式 |
| 生成进度 | 进度条 + 下载链接 | 生成完成后提供下载按钮与保存路径提示 |

**主要操作**：
- 选择数据源与类型后点击“生成”
- 下载到浏览器默认下载目录
- 提供“在文件夹中显示”（受浏览器安全限制，仅本地服务可尝试唤起系统文件管理器）

## 3. 关键交互流程

### 3.1 发起采集

```
点击“开始采集”
    │
    ▼
选择目标卷/盘符（下拉框列出当前可访问的卷，附带容量与文件系统信息）
    │
    ▼
填写配置：别名、哈希策略（默认关闭）、排除规则、备注
    │
    ▼
系统做依赖检查：写权限、SMART 可读取性
    │
    ▼
点击“开始采集” → 进入进度页
    │
    ├─ 实时刷新：已扫描文件/目录、跳过、预估剩余时间
    ├─ 日志区滚动显示当前路径
    ├─ 用户可“暂停/继续”或“取消”
    │
    ▼
采集完成 → 显示摘要卡片
    ├─ “查看快照” → 快照概览
    ├─ “再采一次” → 保留配置重新开始
    └─ “返回首页” → 总览仪表盘
```

**断点续采**：若检测到同盘同卷有未完成的采集记录，进入配置页时弹出询问：“检测到未完成的采集，是否继续？”；选择继续则恢复进度，选择重新开始则清理旧进度。

### 3.2 比对流程

```
进入“对比”页
    │
    ▼
选择 A 快照（左侧）与 B 快照（右侧），提供“交换 A/B”按钮
    │
    ▼
系统检查口径一致性：是否同盘、是否都含哈希
    │
    ▼
点击“开始对比”
    │
    ├─ 后台执行对比任务，页面显示进度条
    │
    ▼
对比完成 → 差异总览
    │
    ├─ 点击“新增/删除/变更/改名移动”卡片过滤文件明细
    ├─ 点击目录行 → 变更下钻页
    │       └─ 切换变更类型，查看该目录下明细
    │
    ├─ 点击文件行 → 右侧滑出详情抽屉
    │
    └─ 点击“导出报告” → 导出/报告页并预填当前对比
```

**改名/移动识别**：仅在 A/B 都启用哈希时生效；未启用时，相同内容的文件移动会显示为“一个删除 + 一个新增”，并在页头黄色提示说明。

### 3.3 搜索/筛选/导出

```
在顶部搜索框输入关键词，或进入搜索页
    │
    ▼
输入关键词 + 选择快照 + 可选筛选条件
    │
    ▼
点击“搜索” → 结果表格即时加载（前 1,000 条）
    │
    ├─ 点击表头排序
    ├─ 添加/移除筛选条件胶囊
    │
    ├─ 点击文件行 → 目录浏览页定位并高亮
    │
    └─ 点击“导出结果” → 导出 CSV（不限制条数）
```

### 3.4 从 Diff 直接定位到目录与文件

- 在对比视图的目录汇总表中，点击目录行的“在快照中打开” → 打开目录浏览页，自动加载并高亮该目录，右侧文件列表默认按“变更类型”排序（新增在前）。
- 在文件明细表中，点击文件名的“在目录中打开” → 打开目录浏览页并高亮该文件。
- 在变更详情抽屉中，提供“查看 A 快照位置”与“查看 B 快照位置”两个链接，分别进入对应快照的目录树。

## 4. 海量数据呈现策略

### 4.1 服务端分页与虚拟滚动

| 场景 | 策略 | 说明 |
|------|------|------|
| 文件列表 | 服务端分页 + 可选虚拟滚动 | 单目录文件数可能数十万，默认每页 200 条，用户可切换 500/1000/全部（切换"全部"时提示性能风险） |
| 目录树 | 懒加载 | 只展开当前节点时加载下一级，不预加载整棵树 |
| 搜索结果 | 服务端 Top-N + 导出完整 | 页面展示前 1,000 条，导出功能可获取全部命中 |
| 对比目录汇总 | 服务端聚合 | 按目录层级聚合的新增/删除/变更数量，分页返回 |
| 对比文件明细 | 服务端分页 + 变更类型过滤 | 默认每页 100 条，按变更类型预过滤 |

### 4.2 Top-N 与“加载更多”

- **Top-N 场景**：最大文件、最近修改、顶层目录占用、扩展名分布，均默认展示 Top 50，提供“显示 100/200/全部”选项。
- **加载更多**：搜索与部分列表采用“加载更多”按钮而非传统分页，避免深分页导航在百万级数据下失真。

### 4.3 筛选与排序

- 所有表格列均支持服务端排序，表头点击切换升序/降序。
- 筛选器统一放在表格上方，以“胶囊标签”展示已生效条件，可一键清除。
- 对目录浏览提供“仅看文件 / 仅看目录 / 全看”快速过滤。

### 4.4 “在资源管理器中打开”的边界

本地 Web 服务运行在用户电脑上，理论上可以唤起本地文件管理器，但存在边界：

| 能力 | 处理方式 | 说明 |
|------|----------|------|
| 打开文件所在目录 | 支持，调用系统能力 | 需要浏览器/本地壳允许唤起本地程序；失败时回退为“复制路径” |
| 打开文件本身 | 谨慎支持 | 仅建议对常见预览格式（图片、文本）提供；大文件避免直接打开 |
| 复制完整路径 | 必须支持 | 作为兜底方案，一键复制到剪贴板 |
| 判断文件是否仍存在 | 本地服务可实时探测 | 快照是历史记录，文件可能已被删除；调用前检查存在性，不存在则禁用“打开” |

**取舍原则**：Web 界面以“浏览与查询”为主，不替代资源管理器；本地打开是辅助功能，永远提供复制路径作为安全兜底。

## 5. 对比视图专门设计

### 5.1 变更类型呈现

| 类型 | 视觉标识 | 判定条件 |
|------|----------|----------|
| 新增 | 绿色 + `+` 徽标 | B 中存在、A 中不存在 |
| 删除 | 红色 + `−` 徽标 | A 中存在、B 中不存在 |
| 变更 | 黄色/橙色 + `~` 徽标 | 同名同路径但大小或修改时间不同；哈希启用时内容不同 |
| 改名/移动 | 蓝色 + `↔` 徽标 | 哈希启用时，同一指纹出现在 A/B 的不同路径 |

**展示方式**：
- 目录汇总表中，每行用四个小徽标显示各类变更数量，徽标为 0 时置灰。
- 文件明细表中，“变更类型”列使用彩色圆点 + 文字标签。
- 改名/移动行同时显示 A 路径与 B 路径，中间用箭头连接。

### 5.2 目录级汇总徽标

- 在目录浏览页，若某目录存在历史对比结果，可在目录名旁显示微型变更徽标（新增/删除/变更数量），提示用户“这里上次动过”。
- 在对比视图目录汇总表中，提供“净大小变化”列，正值绿色、负值红色、零显示“—”。

### 5.3 按变更类型过滤

- 顶部提供四个切换按钮（全部 / 新增 / 删除 / 变更 / 改名移动），支持多选。
- 同时提供扩展名筛选、大小变化范围筛选、时间范围筛选。
- 目录汇总表与文件明细表的过滤条件联动：在目录表选择某目录后，文件明细表默认仅显示该目录下的变更。

### 5.4 两栏文件详情

点击文件行后，右侧滑出详情面板，采用**左右两栏布局**（桌面端）或**上下两栏布局**（窄屏）：

| 字段 | A 快照 | B 快照 |
|------|--------|--------|
| 路径 | 显示 | 显示 |
| 大小 | 显示，差异时高亮 | 显示，差异时高亮 |
| 修改时间 | 显示 | 显示 |
| 创建时间 | 显示 | 显示 |
| 实际占用 | 显示 | 显示 |
| 哈希 | 显示或“未计算” | 显示或“未计算” |
| 属性 | 图标展示 | 图标展示 |

对于删除类，B 栏全部显示“—”；对于新增类，A 栏全部显示“—”；对于改名/移动，路径差异高亮。

## 6. 统计图表建议

优先提供最有信息密度的图表，避免为图表而图表：

| 图表 | 所在页面 | 价值 |
|------|----------|------|
| **快照时间线** | 总览、磁盘详情 | 直观显示每块盘的采集频率与历史 |
| **顶层目录空间占比** | 快照概览 | 一眼判断空间主要被哪个目录占用 |
| **文件大小直方图（对数分箱）** | 快照概览 | 判断“碎小文件多还是大文件多” |
| **扩展名分布 Top-N** | 快照概览 | 判断文件类型构成 |
| **SMART 关键指标趋势** | 磁盘详情 | 发现磁盘健康退化趋势 |
| **对比差异构成饼图/环形图** | 对比视图 | 快速判断变化以新增/删除/变更哪类为主 |

**避免**：3D 图表、复杂雷达图、需要过多交互才能读懂的图表。所有图表都应提供数值标签或悬停提示。

## 7. 中文界面规范

### 7.1 数字与日期格式

| 类型 | 格式示例 | 说明 |
|------|----------|------|
| 文件数 | `2,981,921` | 千分位逗号 |
| 文件大小 | `1.87 TB` / `128.5 MB` / `456 KB` | 自动选择单位，保留 1 位小数；小于 1KB 显示字节 |
| 日期时间 | `2026-09-28 14:32` | 24 小时制，本地时区 |
| 相对时间 | `3 天前` / `刚刚` | 仅用于“最近活动”等轻量场景，悬停显示完整时间 |
| 持续时间 | `23 分 15 秒` / `1 小时 42 分` | 不显示毫秒 |
| 百分比 | `87.3%` | 1 位小数 |

### 7.2 无障碍最低要求

- 所有图标按钮必须带 `aria-label` 或工具提示。
- 表格支持键盘导航（方向键移动焦点，Enter 打开详情）。
- 颜色不是唯一信息载体：新增/删除/变更/改名移动除了颜色外，还有文字标签与徽标形状差异。
- 关键操作（开始采集、取消、导出）不使用仅依赖颜色的提示。
- 对比度满足 WCAG 2.1 AA 级。

### 7.3 深浅色主题建议

建议**默认提供浅色主题，深色主题作为可选项**。

原因：
- 目标用户偶尔使用，浅色主题在阅读大量表格与目录树时更不易疲劳；
- 本地工具类应用通常默认浅色，与系统文件管理器保持一致；
- 深色主题可作为“设置”中的切换项，便于夜间使用或用户偏好。

若资源有限，优先保证浅色主题完美实现，深色主题可在第二阶段补齐。

## 附录：与后端/数据能力的边界说明

本设计文档中提到的“数据能力”包括：
- 按目录层级聚合的大小、文件数、目录数；
- 按扩展名、大小区间、修改时间区间的分组统计；
- 全文索引支持的名称/路径搜索；
- 两快照按路径、大小、修改时间、哈希的匹配与差异分类；
- SMART 数据的读取与历史趋势；
- 采集任务的状态持久化、断点续采；
- 旧版 CSV 快照的导入与转换。

具体以何种接口、何种格式、何种端点提供，由后端设计文档另行定义。
