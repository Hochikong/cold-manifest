# cold-manifest Web 服务 UX 架构设计 v0.3（配套文档）

> 配套主文档：`docs/升级方案-v0.3.md`。本文档面向设计与前端实现，只描述信息结构、页面行为、交互流程与呈现策略；不涉及后端接口、数据库表结构或命令行参数。
> 目标用户：懂技术、不想写 SQL、偶尔使用冷备盘的个人用户。平台：Windows / Linux，中文界面。

## 实现现状说明（2026-10-01）

本文件是最初的 UX 设计稿。前端已经实装为 **7 个路由**（含全局搜索结果页 `/search`），原设计里的 10 个功能页面按「tab / 抽屉 / 弹窗」合并进这些路由中。下面给出设计页面到实际路由的映射表，并在后续章节逐条标注每条设计承诺的实现状态。

| 原设计页面 | 实际落地位置 | 合并方式 |
|-----------|-------------|---------|
| 总览仪表盘 | `/overview` | 独立页面 |
| 快照概览 | `/snapshots?snapshot=<id>&tab=overview` | 快照详情页的「概览」tab |
| 目录浏览与文件列表 | `/snapshots?snapshot=<id>&tab=browse` | 快照详情页的「浏览」tab |
| 搜索页 | `/snapshots?snapshot=<id>&tab=search` | 快照详情页的「搜索」tab |
| 导出/报告页 | `/snapshots?snapshot=<id>&tab=export` | 快照详情页的「导出」tab |
| 重复文件报告 | `/snapshots?snapshot=<id>&tab=duplicates` | 快照详情页的「重复文件」tab |
| 两快照对比视图 | `/diff` 与 `/diff?id=<id>` | 独立页面（选择器 + 详情两态） |
| 变更下钻页 | 合并进 `/diff?id=<id>` | 目录维度 Top 变更卡片 + 文件明细即视为下钻；无独立子页 |
| 磁盘详情页 | `/disks` | 磁盘表格的展开行（`DiskDetailPanel`）+ 卷详情抽屉（`VolumeDetailDrawer`） |
| 采集任务页 | `CollectDialog` 弹窗 | 由「总览 / 快照页」的「开始采集」按钮唤起 |
| 导入旧快照页 | `ImportDialog` 弹窗 | 由「总览 / 快照页」的「导入旧快照」按钮唤起（模式切换：v1 目录 / 登记已封库 db） |
| 任务页 | `/tasks` | 独立页面（支持状态/类型筛选） |
| 全局搜索结果页 | `/search` | 独立页面（顶栏搜索框或 `Ctrl/Cmd + K` 进入；跨快照搜索，支持定位跳转） |
| 设置 | `/settings` | 独立页面（左侧导航底部齿轮入口；含「数据修复」卡片：rebuild 预演 + 执行） |

本轮实机反馈新增（2026-10，均已落地或见标注）：

- **列宽可拖拽（持久化 + 重置）** ✅：主要表格（浏览/明细/任务/查重等）基于 `ResizableTable` 组件——有数字宽度的列可拖拽（最小 64px），按表持久化到 localStorage（`cldm_colw:<tableId>`），表头右键重置该表全部列宽。
- **比对历史分页** ✅：`/diff` 页历史列表走 `GET /api/diffs?limit=&cursor=`（keyset 游标，默认 50 条）；每行显示昵称标签（labels.a / labels.b）。第三轮实机反馈后由**统一分页控件**接管（行数切换 + 上一页/下一页），「加载更多」已移除，见下。
- **昵称（磁盘/卷）展示与编辑** ✅：磁盘页首列、磁盘详情卡、卷详情抽屉均可行内编辑（铅笔进入，Enter 保存 / Esc 取消 / 失焦保存，空串清除，≤64 字符）；采集对话框可选填并在采集成功后自动写入。展示：快照列表/详情用 `label` 作主标题（快照 ID 退为次要信息）、对比页 A/B 选择器与历史列显示标签、CLI `cldm nickname` 与 API `PATCH /api/disks/{id}`、`PATCH /api/volumes/{id}` 均可设置。
- **磁盘健康卡 / 现在读取 SMART** ✅：`DiskDetailPanel` 健康卡显示健康/温度/通电小时/重映射/待定扇区；右上角「现在读取 SMART」按钮现场读一次（`POST /api/disks/{id}/smart/read`，不写历史），失败给出原因（权限不足 / 设备类型无法识别 / 超时等）与原始 stderr 片段。
- **删除被阻塞时的 force 流程** ✅：删除快照被对比引用阻塞时，删除弹窗列出受影响的对比，需勾选「我已确认，同时删除相关对比（force=true）」才能确认。
- **磁盘与卷删除（无级联）** ✅（第三轮实机反馈）：磁盘列表/详情与卷详情抽屉均有删除入口；名下仍有快照或对比时后端拒绝（409）并弹出阻塞清单（可点跳转对应快照/对比），干净才真正删除——绝不级联删快照。
- **对比结果删除** ✅（第三轮实机反馈）：对比历史列表每行有删除按钮；删除的是物化库与登记行，不影响两侧快照；对比正在物化时提示稍后再删（409）。
- **统一分页控件（行数 + 上/下一页）** ✅（第三轮实机反馈）：`CursorPager` 组件统一了各表格的分页——行数切换 20/50/100/200（默认 50）+ 上一页/下一页（走 keyset 游标栈，不用 OFFSET）；覆盖对比明细/历史、快照浏览、快照内搜索、全局搜索、重复文件、跳过项、任务；旧「加载更多」按钮已全部移除。
- **对比明细右键按侧跳转** ✅（第三轮实机反馈）：右键"打开所在快照浏览"按行类别跳——新增行跳 B 侧（用 B 路径）、删除行跳 A 侧、其余变化行给 A/B 两项子菜单。
- **磁盘页并排布局与横滚修复** ✅（第三轮实机反馈）：磁盘详情并排卡片此前会被趋势图 canvas 的固定像素宽撑出页面级横向滚动条（曾被撑到百万像素宽）；已用 `contain: inline-size` 把面板内在宽度与内容解耦根治，宽窗/窄窗（约 1100px）均无横滚。
- **刷新语义** ✅（第三轮实机反馈）：删快照后自动失效对比等关联缓存；主列表在点侧边菜单进入时总是重新拉取（`refetchOnMount: 'always'`），不用 F5 也能看到最新。
- **SSD 专属指标与趋势** ✅（第四轮实机反馈）：磁盘详情面板新增 SSD 专属区块——剩余寿命进度条、累计写入/读取 TB、备用块、介质错误、异常断电、通电次数、控制器忙时、多温度探头（机械盘不显示，提示"SSD 盘重新采集一次 SMART 后会显示"）；SMART 趋势图新增「寿命剩余 %」「累计写入量」两个指标；身份卡新增「介质类型」徽标（固态·NVMe / 固态·SATA / 机械 / 未识别）。采集口径与落库列见《升级方案》§4.4。
- **磁盘详情面板宽度与列宽解耦** ✅（第四轮实机反馈）：`DiskDetailPanel` 加 `PanelWidthGate`——面板内容宽度改为实测表格滚动容器（`.ant-table-content`）的可视宽度（上限 1200px、左对齐），表格横向滚动时面板 `sticky left:0` 保持可见。用户拖宽表格列后，并排的详情卡片不再被拉长或挤压。
- **分页状态记忆（行数持久化 + URL page + 刷新恢复）** ✅（第四轮实机反馈）：统一分页控件升级为"可记忆"——每页行数按表存浏览器本地（localStorage `cldm_pagesize:<tableId>`），下次进页直接用上次选的行数；当前页写进网址 `?page=`（不打新历史记录），**刷新或把带页码的链接发给别人的时候能自动回到原页**（从第 1 页沿游标自动走 N-1 步恢复，超过 20 页会提示回第 1 页）；筛选/排序变化时回第 1 页并清掉网址里的页码。覆盖对比明细/历史、快照浏览/搜索、全局搜索、重复文件、跳过项、任务。

状态图例：

- **✅ 已实现**：代码已落地，当前可直接使用。
- **◐ 部分实现**：核心能力有了，但体验或范围有明确缺口。
- **✗ 未实现**：当前没有对应实现；若属于用户 2026-10-01 明确决定不做的范围，标注「**暂不做（2026-10-01 决定）**」；已决定要做的标注「**已排期（2026-10-01 决定）**」；尚无结论的标注「未实现（需求未拍板）」。

## 1. 信息架构与导航模型

### 1.1 一级栏目

> ✅ 已实现。当前左侧导航固定 6 个入口：总览、快照、对比、磁盘、任务、设置（齿轮在底部）。

采用**固定左侧导航 + 顶部上下文工具栏**的经典本地工具布局。左侧导航常驻 5 个一级入口，按使用频率与心智模型排列：

| 顺序 | 栏目 | 定位 | 典型访问频率 |
|------|------|------|--------------|
| 1 | **总览** | 所有磁盘、快照、健康状态、最近任务的一站式入口 | 每次打开 |
| 2 | **快照** | 单个快照的浏览、统计、搜索、目录树 | 高频 |
| 3 | **对比** | 两快照差异分析，含目录级汇总与文件级明细 | 中频 |
| 4 | **磁盘** | 物理盘详情、SMART 历史、卷与盘符映射 | 低频但关键 |
| 5 | **任务** | 采集、导入、导出、报告生成的配置与进度 | 每次接新盘 |

底部固定入口：**设置**（图标齿轮，不纳入主要流程）。

### 1.2 全局导航元素

> ✅ 已实现。通知中心已完整实现；全局搜索（顶栏 + `Ctrl/Cmd + K` + `/search` 结果页）也已落地。

- **应用标题栏**：左侧显示应用名与当前环境标签（如 `cold-manifest · 本地服务`），右侧显示服务状态指示灯（运行中 / 任务进行中 / 出错）。
  - ✅ 已实现：标题栏显示「冷备清单 · 元数据采集与比对」，服务状态灯当前未显示。
- **左侧导航**：图标 + 文字，当前项高亮；当某个栏目下有未完成的重要任务时显示小型徽标（例如任务栏显示“1 个采集中”）。
  - ◐ 部分实现：导航高亮已实现；栏目级任务徽标未实现。
- **全局搜索框**：顶部栏右侧放置“快速搜索”，回车后进入搜索页并预填关键词；支持快捷键 `Ctrl/Cmd + K`。
  - ✅ 已实现（2026-10 本轮）：顶栏全局搜索 `GlobalSearch` 组件 + `Ctrl/Cmd + K` 快捷键 + `/search` 结果页（跨快照，prefix/fulltext 两模式，命中显示所在快照与路径，支持定位跳转到该快照浏览）—— `GET /api/search`。
- **通知中心**：右上角铃铛图标，聚合任务完成、错误、磁盘接入/拔出事件；点击展开抽屉，保留最近 50 条。
  - ✅ 已实现：右上角铃铛，显示最近 20 条已终态任务，支持全部标记已读，点击可跳转到快照/对比/任务页。

### 1.3 面包屑与上下文操作

> ◐ 部分实现。快照浏览 tab 内有面包屑；结果/明细表格右键菜单已实现；上下文工具栏未实现。

- **面包屑**：用于快照浏览、目录下钻、对比结果三类深导航页面，形式为 `快照 / photos / 2023 / 事件`。
  - ◐ 部分实现：快照「浏览」tab 中显示 `根目录 / 当前：xxx` 形式的面包屑；对比页无面包屑。
- **上下文工具栏**：进入具体快照或对比会话后，顶部出现该对象的专用工具栏，包含：
  - 快照名 / 对比会话名
  - 关键指标（文件数、总大小）
  - 主要操作按钮（导出、刷新、关闭）
  - 视图切换（列表 / 图表 / 树）
  - ✗ 未实现（需求未拍板）。当前采用 Tabs 切换，无独立上下文工具栏。
- **右键菜单**：文件与目录行支持右键唤起“复制路径”“在资源管理器中打开”“加入筛选”等操作。
  - ◐ 部分实现（2026-10 本轮）：搜索结果与对比明细表格已支持右键菜单（`RowContextMenuOverlay`）：复制路径 / 复制文件名 / 打开所在快照浏览；「在资源管理器中打开」暂不做（2026-10-01 决定）。

### 1.4 页面状态约定

> ✅ 已实现。骨架屏、空态、错误横幅均已覆盖主要页面。

- **空态**：页面首次使用或没有数据时，中央展示插画 + 一句说明 + 一个主操作按钮（如“接入磁盘并采集”）。
  - ✅ 已实现：`Empty` 组件覆盖无数据场景。
- **加载态**：表格骨架屏，目录树节点显示旋转占位，进度页显示实时日志与百分比。
  - ✅ 已实现：表格用 `Skeleton` / `Spin`；目录树用 `Spin`；任务进度用进度条 + 状态消息。
- **错误态**：顶部红色横幅 + 可展开的“详情”区域；不影响页面其他可用区域。
  - ✅ 已实现：`ErrorAlert` 组件在页面顶部显示，不阻塞其他区域。
- **部分失败**：采集或对比过程中出现可恢复错误（如部分文件跳过）时，用黄色警告条提示，并提供“查看日志”入口。
  - ◐ 部分实现：部分失败通过 `Alert` 展示；统一“查看日志”入口未做，需去 `/tasks` 查看任务详情。

## 2. 页面清单与每页规格

| 磁盘列表 | 表格 | 每行一块物理盘：别名、型号序列号、容量、最近快照日期、健康状态徽标、操作入口 | ✅ 已实现（在「磁盘与卷」卡片中） |

### 2.2 快照概览

> ◐ 部分实现。核心统计、扩展名/大小/深度图表、顶层目录占用、最大文件 Top 50 已实现；最近修改 Top-N、「与上一个快照对比」未实现。

**目的**：展示单个快照的统计画像，帮助用户快速判断“这张快照长什么样”。

**关键区块**：

| 区块 | 组件 | 说明 | 状态 |
|------|------|------|------|
| 快照信息头 | 标题 + 元数据 | 快照名、所属磁盘、采集时间、持续时间、是否含哈希、备注 | ✅ 已实现：显示快照 ID、卷 ID、采集时间、哈希策略、跳过项；备注可编辑（PATCH pinned/notes，2026-10 本轮） |
| 核心统计 | 4 个 KPI 卡片 | 文件总数 / 目录总数 / 总逻辑大小 / 实际占用空间 | ✅ 已实现：文件总数、目录总数、总逻辑大小、最深层级 |
| 文件类型分布 | 环形图 / 横向条形图 | 按扩展名聚合 Top 10，其余归入“其他” | ✅ 已实现：扩展名 Top 10（按数量）横向条形图 |
| 文件大小直方图 | 柱状图 | 横轴为对数区间（<1KB / 1KB–1MB / 1MB–1GB / 1GB–10GB / >10GB），纵轴为文件数 | ✅ 已实现 |
| 顶层目录占用 | 树图 / 横向条形图 | 每个顶层目录的聚合大小，支持点击进入目录浏览 | ✅ 已实现：表格展示，但未接入点击下钻 |
| 最大文件 Top-N | 表格 | 默认 Top 50，列：名称、路径、大小、修改时间；支持点击路径进入目录 | ✅ 已实现 Top 50；点击路径进入目录未实现 |
| 最近修改 Top-N | 表格 | 按修改时间倒排，默认 50 条 | ✗ 未实现（需求未拍板） |

**主要操作**：
- “浏览目录”进入快照浏览页，默认定位根目录
  - ✅ 已实现：切换到「浏览」tab。
- “搜索本快照”进入搜索页并绑定当前快照

| 能力 | 处理方式 | 说明 | 状态 |

## 附录 A：实现现状功能索引

以下按当前实际路由列出已落地的入口与能力，并注明对应 API（简短）。

### `/overview` 总览

- 4 个 KPI 卡片：磁盘/卷数、快照总数、最近一次采集、历史对比任务 —— `GET /api/volumes`、`GET /api/snapshots`、`GET /api/diffs`
- 「开始采集」按钮 —— 打开 `CollectDialog`
- 「导入旧快照」按钮 —— 打开 `ImportDialog`
- 磁盘与卷列表 —— `GET /api/volumes`
- 按卷分组的快照时间线 —— `GET /api/snapshots`
- 最近 10 条对比记录 —— `GET /api/diffs`

### `/snapshots` 快照

**列表态**
- 快照分页列表（id、卷、采集时间、文件数、总大小、操作、**置顶星标**） —— `GET /api/snapshots`（每行带 `pinned`）
- 星标置顶 + 「只看置顶」开关 + 按卷筛选 —— `PATCH /api/snapshots/{id}`（pinned）+ 前端过滤
- 备注编辑 —— `PATCH /api/snapshots/{id}`（notes）
- 查看快照详情 —— 跳转 `?snapshot=<id>&tab=overview`
- 删除快照 —— `DELETE /api/snapshots/{id}`，支持 `on_disk=keep|delete`、`force=true`；409 阻塞时展示关联 diff/任务并需勾选确认

**快照详情态（Tabs）**
- **概览** `tab=overview`
  - 文件总数、目录总数、总逻辑大小、最深层级 —— `GET /api/snapshots/{id}`
  - 扩展名 Top 10、文件大小分布、深度分布 —— `GET /api/snapshots/{id}/stats`
  - 顶层目录占用 Top —— `GET /api/snapshots/{id}/du`
  - 最大文件 Top 50 —— `GET /api/snapshots/{id}/stats`
  - 删除快照入口 —— `DELETE /api/snapshots/{id}`
- **浏览** `tab=browse`
  - 左侧目录树懒加载 —— `GET /api/snapshots/{id}/tree?parent_id=...`
  - 右侧文件/目录列表，支持服务端排序、类型/扩展名/大小/名称筛选与 Top-N 切换 —— `GET /api/snapshots/{id}/entries`
  - 面包屑与返回根目录 —— 查询参数 `parent_id`
  - 文件详情抽屉
- **哈希面板**（`HashPanel`）
  - 哈希策略与范围设置、一键候选指纹、完整哈希（含代价说明）、单组精验 —— `POST /api/snapshots/{id}/hash`
- **跳过项**（`SkippedPanel`）
  - 跳过/告警记录列表 —— `GET /api/snapshots/{id}/skipped`
- **重复文件** `tab=duplicates`
  - 按完整哈希分组，统计重复组数、可回收空间、已哈希文件数 —— `GET /api/snapshots/{id}/duplicates`
  - 最小文件大小分段切换（0 B / 1 MiB / 10 MiB / 100 MiB）
  - 展开组查看路径列表
- **搜索** `tab=search`
  - 前缀搜索与全文搜索切换（全文依赖 FTS5 索引） —— `GET /api/snapshots/{id}/search?q=...&mode=prefix|fulltext`
  - 类型过滤（文件/目录）、扩展名过滤
  - 结果表格（统一分页控件：行数切换 + 上/下一页）
- **导出** `tab=export`
  - 导出 CSV（entries 全表） —— `GET /api/snapshots/{id}/export?format=csv`
  - 导出 V1 CSV（zip，兼容旧版） —— `GET /api/snapshots/{id}/export?format=v1_csv`
  - HTML 报告（分节勾选：overview / extensions / sizes / depth / topdirs / skipped） —— `GET /api/snapshots/{id}/report?format=html&sections=...`
- **盘上副本**（`OnDiskCopyBadge` + `VerifyCopyCard`）
  - 副本状态徽标（存在/缺失/校验时间） —— `GET /api/snapshots/{id}`
  - 副本校验按钮（抽样/全量） —— `POST /api/snapshots/{id}/verify-copy`（body `scope=sample|full`）
- **索引补建**
  - 补建 FTS 全文索引 —— `POST /api/snapshots/{id}/build-fts`（任务化）
  - 补建统计预计算 —— `POST /api/snapshots/{id}/build-stats`（任务化）

### `/search` 全局搜索

- 顶栏搜索框（`GlobalSearch`）+ `Ctrl/Cmd + K` 快捷键 —— 跳转 `/search?q=...`
- 跨快照搜索，prefix / fulltext 两模式（fulltext 依赖各库 FTS 索引） —— `GET /api/search?q=&mode=prefix|fulltext`
- 结果显示所在快照与路径，支持定位跳转到该快照浏览；统一分页控件（keyset 游标栈上/下一页 + 行数切换）

### `/diff` 对比

- 发起新对比：选择 A/B 快照、交换、hash 策略（none/sha256） —— `POST /api/diffs`
- 历史对比列表（含删除按钮） —— `GET /api/diffs` · `DELETE /api/diffs/{id}`（物化中 409）
- 对比详情：A/B 信息、8 类变更卡片过滤、证据等级标签、Windows 大小写改名提示（hints） —— `GET /api/diffs/{id}`
- 差异构成饼图、目录维度 Top 变更 —— `GET /api/diffs/{id}/summary`
- 文件明细表格，支持按变更类型过滤、**路径前缀过滤**、右键菜单（按行类别跳对应侧快照：新增→B、删除→A、变化→A/B 子菜单） —— `GET /api/diffs/{id}/entries?path_prefix=...`
- 两栏抽屉：A/B 路径、类型、大小、修改时间
- 下载 HTML 报告 —— `GET /api/diffs/{id}/report`
- 导出 CSV —— `GET /api/diffs/{id}/export`

### `/disks` 磁盘与卷

- 磁盘表格：ID、型号、序列号、USB 桥/控制器、接口、容量、卷数、快照数 —— `GET /api/disks`
- 展开行显示磁盘详情：
  - 身份与容量卡片 —— `GET /api/disks/{id}`
  - 健康状态卡片（SMART 或降级提示） —— `GET /api/disks/{id}`
  - SMART 历史趋势图（温度/通电小时切换） —— `GET /api/disks/{id}/smart`
  - 卷列表 —— `GET /api/disks/{id}`
  - 快照时间线 —— `GET /api/disks/{id}`
  - 该盘各卷的历次快照趋势图 —— `GET /api/volume-trends/{volume_id}`
  - 删除磁盘（不级联：名下仍有快照/对比 → 409 阻塞清单，可点跳转） —— `DELETE /api/disks/{id}`
- 卷详情抽屉（`VolumeDetailDrawer`）：卷身份、该卷快照列表、容量趋势、删除卷（同上不级联） —— `GET /api/volumes/{vid}` + `GET /api/volumes/{vid}/trends` + `DELETE /api/volumes/{vid}`

### `/tasks` 任务

- 任务列表（id、类型、状态、批次、进度、创建/结束时间、操作、结果），支持**状态筛选**与**类型筛选** —— `GET /api/tasks`
- 取消待处理/运行中任务 —— `POST /api/tasks/{id}/cancel`
- 任务列表（统一分页控件：行数切换 + 上/下一页）
- 批次详情抽屉：状态、根路径、计划卷、子任务进度 —— `GET /api/batches/{id}` + `GET /api/tasks?batch_id=...`

### `/settings` 设置

- 数据根目录等配置只读展示 —— `GET /api/settings`
- 「数据修复」卡片（`RebuildCatalogCard`）：catalog 重建预演 + 执行 —— `POST /api/admin/rebuild-catalog`（dry_run 预演）

### 全局组件

- **通知中心** `NotificationBell`：右上角铃铛，展示最近 20 条已终态任务，支持跳转与全部标记已读 —— `GET /api/tasks?limit=20`
- **任务完成提醒**：页面右上角自动弹出完成/失败通知，可跳转查看快照/对比/任务 —— `GET /api/tasks?limit=20` + 轮询
- **全局搜索** `GlobalSearch`：顶栏搜索框 + `Ctrl/Cmd + K`，回车进入 `/search` 结果页
- **右键菜单** `RowContextMenuOverlay`：搜索结果 / 对比明细 / 浏览表格行右键，复制路径、复制文件名、打开所在快照浏览（对比明细按行类别跳对应侧：新增→B、删除→A、变化→A/B 子菜单，支持 `extraOpenItems` 子菜单项）
- **统一分页控件** `CursorPager`：行数切换 20/50/100/200（默认 50）+ 上一页/下一页（keyset 游标栈）；对比明细/历史、快照浏览、快照内搜索、全局搜索、重复文件、跳过项、任务均已接入
- **导入对话框** `ImportDialog`：模式切换（v1 目录扫描导入 / 登记已封库 snapshot.db） —— `POST /api/imports` · `POST /api/imports/db`
