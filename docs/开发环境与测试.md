# 开发环境与前端测试

> 状态：已配置并验证（2026-09-28）。适用：WSL2 + Windows 宿主。
> 相关文档：`升级方案-v0.3.md`（P0 起的前端工程按本文方式做自动化验证）。

## 1. 环境拓扑

- 代码与工具链在 WSL2（Ubuntu 24.04，发行版 `ocv2`）内；Windows 宿主负责浏览器、编辑器与 OpenCode 桌面端。
- 开发期两个进程都在 WSL 内：
  - 后端 FastAPI：`--host 0.0.0.0 --port 8765`
  - 前端 Vite dev server：`npm run dev -- --host`（默认端口 5173）
- Windows 侧访问：WSL2 NAT 模式自带 localhost 转发，浏览器直接打开 `http://localhost:5173` 与后端 `http://localhost:8765/docs`（Swagger UI）。不通时改用 `wsl hostname -I` 返回的 IP。
- Vite 把 `/api` 代理到后端，开发期无 CORS 问题；生产由后端同源托管。

## 2. Agent 浏览器自动化（Playwright MCP）

- 项目级注册在仓库根 `opencode.json`（只对本项目生效，不影响其他项目）：

  ```json
  "mcp": { "servers": { "playwright": {
    "type": "local",
    "command": ["npx", "-y", "@playwright/mcp@latest", "--headless", "--browser", "chromium", "--isolated",
                "--output-dir", "/tmp/opencode/playwright-mcp"]
  } } }
  ```

- 浏览器为 Chrome for Testing 154（`~/.cache/ms-playwright/chromium-1246`），无头运行，不需要 GUI。
- `designer` agent 已获得 `playwright` MCP 权限（用户级插件配置 `oh-my-opencode-slim.json` 里的权限位；MCP 本体是项目级，其他项目不会因此启动任何进程）；其他 agent 需要时同样追加。
- 已验证：无头启动 → 页面导航 → 截图（本会话实测通过）。
- 输出目录：MCP 自动命名的截图/文件落到 `--output-dir`（本机为 `/tmp/opencode/playwright-mcp`），避免污染仓库根目录。
- 注意：截图工具参数本版本要求 `scale`（如 `scale: "css"`）。
- 一次性安装命令（更换机器时照做）：

  ```bash
  sudo env "PATH=$PATH" npx playwright install-deps chromium        # 系统运行库（Ubuntu）
  npx -y @playwright/mcp@latest install-browser chrome-for-testing  # 浏览器本体（与 MCP 版本对齐）
  ```

  ⚠️ 不要用 `npx playwright install chromium` 代替第二条：它可能装到与 MCP 内置 Playwright 不匹配的修订版（本项目遇到过 1243 vs 1246），表现为 `Browser "chrome-for-testing" is not installed`。

## 3. E2E 回归测试

- 前端脚手架加入 `@playwright/test` devDependency，用例放 `frontend/e2e/`，`baseURL` 指 `http://localhost:5173`。
- 运行：`npx playwright test`；P0/P1 验收指标（导入对账、浏览性能、diff 正确性等）用它出一致性证据。
- 项目内 Playwright 版本以 package.json 锁定；浏览器缺失时 `npx playwright install chromium` 并按提示补依赖。

## 4. 故障排查

| 症状 | 处理 |
|---|---|
| MCP 报 `Browser "chrome-for-testing" is not installed` | `npx -y @playwright/mcp@latest install-browser chrome-for-testing` |
| Chromium 启动报缺 `.so` | `sudo env "PATH=$PATH" npx playwright install-deps chromium` |
| sandbox 启动错误 | 在 MCP 命令后加 `--no-sandbox`（改 `opencode.jsonc`） |
| Windows 打不开 localhost | 确认服务绑 `0.0.0.0`；或改用 `wsl hostname -I` 的 IP |
| 会话里没有 `playwright.*` 工具 | 重启 OpenCode 或新开会话 |
