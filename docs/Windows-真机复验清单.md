# Windows 真机复验清单（2026-10-01）

> 用途：这一轮修了多处 Windows 专属问题（URI/路径、文件占用、控制台编码、Excel 乱码等），
> 其中一部分在 WSL 里没法真机判定。请按下面清单在你的 Windows 机器上过一遍，
> 有问题就把**截图 + 控制台报错 + 后端日志片段**发我。
>
> 包：`dist-packages/cold-manifest-0.2.0-win.zip`（解压即用，含 Windows 与 Linux 启动脚本）。

## 0. 准备
1. 解压到一个**新目录**（例如 `D:\cldm-test\`；路径含空格/中文/`..` 现在也都支持，但建议先用普通路径做首轮）。
2. 双击 `setup.cmd`（离线安装，无需联网）。
3. 双击 `start.cmd`；浏览器打开 `http://localhost:8765`。
   - 首次运行 Windows 防火墙可能弹窗（我们监听 0.0.0.0 是为了局域网访问）——允许即可。

## 2. 常规冒烟（每轮都值得过一遍）
- 采集一块真盘（含多层目录、空目录、中文或空格文件名、`$RECYCLE.BIN` 之类系统目录）
  → 总数/总字节与 v1 或资源管理器对账；跳过项 tab 能看到原因
- 概览/浏览/搜索/跳过项/导出/重复文件 逐 tab 打开，**控制台无红色报错**
- 任务页：跑一次采集 + 一次哈希，进度与「已完成」通知正常；点取消能停
- 通知铃铛：任务完成后有未读；「全部已读」有效
- 设置页：数据根、导入根等展示正确

## 3. 已知边界（不算 bug）
- **mac 不支持**（按你的决定）。
- **不设鉴权**、局域网可访问：同网段任何设备都能打开页面，别放在不受信的网络上。
- **SMART 依赖第三方工具**：Windows 需要 smartmontools；USB 桥接盘可能需 `-d sat`（程序会自动重试一次）。
- **数据根放在 exFAT/FAT32（U 盘）**：catalog 会自动从 WAL 回退到 DELETE 日志模式（会有 warning 日志），功能正常但性能略低。
- **路径极长（>260 字符）**：需在 Windows 打开"长路径支持"（组策略/注册表）；程序会在检测到很深的根路径时给提示。
- **指纹档 ≠ 逐字节验证**：抽样指纹（首/中/尾各 64KB）"高度可能重复"，要作为删除依据请用「按内容」档。
