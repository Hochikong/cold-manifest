## 3. 已知问题与限制（非阻塞，按优先级）

1. **stats 冷查询 ~2s 贴边**（设计预算 2s）：已优化到覆盖索引分段聚合；P1 可加进程内缓存或单趟 CASE 聚合。前端现已显示加载态而非"暂无数据"。
2. **对比徽标 8 类**（added/removed/size/mtime/type/content/moved/identical）比 UX 文档 §9 的 4 类更细；当前按 8 类展示，文档可在 P1 同步。
3. **oxlint 既有告警**（React Compiler 跳过优化）：`DiffPage`/`SnapshotsPage` 存在 `useEffect` 内 setState 与 `useMemo` 依赖问题，功能正常。
4. **任务页/报告导出**：占位（P1 范围：采集任务、SSE 进度、HTML 报告）。
5. **9p 性能陷阱**：仓库内 `data/`（/mnt/c）I/O 慢约 20 倍；开发与性能验证统一用 WSL 原生盘 `/home/jack2/cold-data`。
6. **环境级问题**：子会话中 `glob`/`grep` 工具会被中断（已复现并写入项目记忆与开发文档）；Playwright MCP 已钉版本 `0.0.83` 规避启动超时。
